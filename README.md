## 给 Agent 的工程方法详细解释

Agent 的工作基于四层知识架构，从通用理论到实战修正逐层递进。

### 第一层：环境物理特性

运行前通过 AGENTS.md 注入 15 条环境行为规律（定性描述）。这些是 agent 在实际飞行前无法从文档获得的"暗知识"，包括：

- 真空燃料跨块馈送失效 → 必须规划 Fuel Line
- 高速大角度翻转受风标力矩锁死 → 减速方案不得依赖空中翻转
- 引擎差动真空中零力矩 → 真空段姿态只能靠动量执行器
- 气动舵面转向力矩可忽略 → 大气段转向靠姿态-推力耦合
- 爆炸式分离器有分离冲量 → 分离前后需差分标定
- 等等

Agent 读懂这些后，能在设计阶段就规避已知坑。

### 第二层：GNC 工程知识手册

覆盖从轨道力学到着陆设计的通用理论（handbook ~250 行）：

- **轨道力学**：轨道根数估计、vis-viva、Hohmann 转移、Kepler 外推、角动量守恒
- **大气物理**：阻力衰减趋势、终端速度概念、速度平台对策
- **上升制导**：两段式架构、速度平台对策、插入判据
- **姿态控制**：四元数误差 + PD、对准死区门控、风标力矩约束
- **减速与着陆**：悬停刹车推力分配、重力损失理论、弹道下坠 + 刹车包线、E-导引终端制导
- **着陆稳定性**：倾覆角公式、着陆冲击理论、静态/动态稳定性
- **设计方法论**：四大预算、探针阶梯、常见失败模式检查项

### 第三层：通用 GNC 数学库（gnc_lib/）

将手册中的公式实现为可直接调用的 Python 函数（零依赖纯标准库）：
- 轨道根数估计、Kepler 外推、Hohmann Δv
- 弹道落点数值预报（含角动量守恒 + 可标定阻力）
- 四元数姿态误差 + PD
- PID/PD（抗饱和/限幅/死区）

### 第四层：实战修正（自维护 knowledge.md）

Agent 在运行中发现的新行为、被证伪的方案、有效做法——作为自己的长期工程记忆。

### 设计流程

```
建造前：
  四大预算表（质量/推重比、燃耗、控制权限、结构供油）→ 不合格则重新设计
  着陆静态稳定性预验算（倾覆角 ≥ 预期扰动角）

建造后：
  探针阶梯：质量探针 → 静态点火 → 悬停探针 → 短距爬升
  全部通过 → 才允许飞全任务

飞行后：
  闸门验证（从 trajectory.csv 实测，禁止仅凭 done=true）
  失败诊断 → knowledge.md 记录 → 迭代
```

### 迭代纪律

1. 单变量原则：每轮只验证一个改动
2. 离线门：上机前先过离线仿真预测
3. 已知好配置锚点：连续劣化即回滚
4. 假设驱动：每轮记录 改动/预期/实测/归因
5. 自我复盘：每 5-10 轮或遇瓶颈时，重读知识文件+审视架构

## 最终方案细节

### 机器设计

- 垂直堆叠：Starting Block → Fuel Barrel Big ×3（中心线）→ Booster ×4（底部环）→ Payload（顶部 Decoupler 后）
- 着陆腿：16 段 L 形木质结构（脚点半径 4.0 单位）+ Grip Pad 防滑
- 重心管理：重组件（引擎+满油箱）靠近底部，降低 h_CG
- 跨油箱供油：Fuel Line 网络（fuller supplies emptier）

### 控制器架构（11 相状态机）

```
pad → loft → boost → gravity_turn → insertion_check
  → orbit_raise(Hohmann) → separation
  → payload_coast(被动监视)
  → retro_window(闭式落点预报)
  → kill_burn(两段式) → final_descent(分段PI)
  → touchdown → endpoint_hold
```

- **姿态**：四元数误差 + PD，对准死区门控（先对准后出力）
- **油门**：矢量分配（侧向修正参与幅值）
- **落点预报**：标定阻力弹道数值积分，每帧重解算
- **触地**：静止判据 + 触地速度门 + 末段 PI 收敛

### 闸门验证

每轮 run 结束后从 trajectory.csv 实测 G1-G5（不依赖控制器 self-report）：
- G1：从分离帧逐帧累加径向角 ≥ 1080°
- G2：qualifying 区间每帧 r > 1100
- G3：完整度 ≥ 0.90
- G4：球面弧距 < 50 且直立且静止 10s
- G5：无人工 + 可重建

## 迭代过程

项目经历了多轮迭代（详见 iterations.md），关键转折：

1. 推力方向约定修正（喷焰方向 ≠ 推力方向）
2. 垂直爬升 + vr 节流环比重力转弯省 60% 燃料（到 alt 410 只需 33.6 单位）
3. 切向目标速度必须取 min(vcirc(target), vcirc(current))——否则高轨误判逃逸
4. 分离冲量需要差分标定 + 补偿脉冲
5. 姿态权限必须结构级保证（细长堆叠风标扰动超轮控两个数量级）

每轮迭代的改动/假设/实测/归因详见 iterations.md。
